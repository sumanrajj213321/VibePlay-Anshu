# VibePlay3D

A lightweight original Godot 4 mobile 3D adventure prototype for VibePlay.

## Open on Android
1. Download the `godot/VibePlay3D` folder from this repository.
2. In Godot Android Editor, choose **Import**.
3. Select the folder containing `project.godot`.
4. Open the project and press **Run**.

## Controls
- Touch and drag on the left half of the screen to move.
- Drag on the right half to rotate the camera.
- Keyboard arrow keys also work in the editor.

This is a solo prototype foundation. Online multiplayer, friend invites, account avatars, statistics, and the separate BlockCraft mode are not implemented yet. It is an original game concept, not Roblox or Minecraft content.
